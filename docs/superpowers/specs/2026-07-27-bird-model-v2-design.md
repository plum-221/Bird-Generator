# Bird Generator 鹦鹉模型 V2 设计规格

## 目标

重做默认鹦鹉，使其首先能辨认出参考照片中奶油白虎皮鹦鹉的体态与面部特征，同时保留原项目的可爱三渲二风格。视觉比例确定为：70% 真实虎皮鹦鹉特征，30% 日系动漫化表达。

## 当前问题

- 身体近似横向圆球，缺少照片中直立、上窄下宽的梨形轮廓。
- 头和身体以两个明显球体拼接，缺少虎皮鹦鹉从额头到胸腹的连续羽毛曲线。
- 两侧翅膀过厚、过圆，像额外长出的团块；真实翅膀应贴合身体并向尾部收尖。
- 尾羽被身体遮挡且太短，无法建立虎皮鹦鹉最关键的长尾识别特征。
- 喙、鼻蜡膜、脚爪和脸颊细节过于简化，没有宠物本体的辨识度。
- 材质偏灰、描边偏重，眼睛没有高光和表情，整体不像用户期望的日系动漫角色。

## 路线比较

### A. 只调整现有球体比例

改动小，但翅膀、尾羽和头身连接的基础结构不正确，最多让圆球变瘦，无法解决“不像鹦鹉”。不采用。

### B. 保留程序化接口，重建鸟体几何（采用）

保留参数、动作状态机、导出和交互契约，重写 `birdBuilder.js` 中的可见模型。能在不破坏网站功能的前提下真正改变轮廓，并继续支持捏鸟。

### C. 使用外部雕刻模型

外形上限最高，但会弱化参数化能力，增加资源体积和骨骼适配成本，也不利于保持开源项目的纯程序化特点。本轮不采用。

## 默认造型

### 轮廓

- 身体改为直立梨形：肩部较窄，胸腹饱满但不横向膨胀，腹部最低点自然接腿。
- 头部稍大但不做“大头娃娃”；额头圆润，后脑向背部平滑过渡，减少明显颈缝。
- 正面保持轻微歪头，使默认角色更像参考照片中警觉又有点呆萌的站姿。
- 翅膀使用贴身的扁平水滴形主翼，末端指向尾部；叠加少量羽片轮廓，不做厚重球体。
- 两根主尾羽明显露出，向后下方延伸约半个身长；辅尾羽较短，形成层级。
- 双腿细而略分开，脚趾采用虎皮鹦鹉的对趾结构表达，颜色为浅灰粉。

### 面部

- 黑色圆眼保留真实比例，只放大约 10% 作为动漫化处理。
- 每只眼睛增加主高光和柔和次高光；眨眼仍由现有动画驱动。
- 喙改为上下两段的短钩形结构，主色暖黄；上方增加浅粉米色鼻蜡膜。
- 增加很淡的灰米色额纹、脸颊羽和小型喉点，避免纯白面部变成无特征圆脸。
- 表情保持温和、略呆，不加入人类眉毛或夸张睫毛。

### 材质与动漫感

- 主羽色由灰白改为奶油白，胸腹带轻微暖色渐层，翅膀和尾羽使用略冷的象牙白区分层次。
- 描边改为暖深灰，并比当前细约 20%，避免脏重。
- 采用三段式明暗：亮面柔和、阴影偏暖、边缘高光克制；不追求写实羽毛纹理。
- 动漫感来自清晰剪影、眼睛高光、柔和配色和有节奏的微动作，而不是把鸟拟人化。

## 动态表现

- 待机呼吸由整体缩放改为胸腹轻微起伏，避免模型像气球。
- 增加偶发歪头、快速眨眼、单侧翼轻抖和尾羽回弹。
- 现有 14 个动作继续使用，但重新校准翼根、尾根、头部和脚部锚点。
- 动作幅度遵循小型鹦鹉：快速、短促、带一点停顿，不做猫式缓慢摆动。

## 品牌图

重新生成透明背景的 2D 日系动画小鹦鹉图。必须保留奶油白羽色、黑豆眼、暖黄钩喙、浅色鼻蜡膜、直立梨形身体和长尾；画面使用柔和赛璐璐上色，不加入人物、笼子或复杂背景。

## 模块边界

- 主要重写：`src/birdBuilder.js`。
- 配套调整：`src/birdParams.js`、`src/birdPresets.js`、`src/birdMotionRig.js`、品牌图资源与相关测试。
- 保持不变：场景、相机、天气、物理玩具、分享卡、三语 UI、GLB 导出入口和 GitHub Pages 架构。
- 继续兼容现有 `userData` 接口，避免牵连 `main.js` 的公共流程。

## 验收标准

1. 缩小截图观看时，也能仅凭直立梨形身体、贴身翅膀和长尾认出是虎皮鹦鹉。
2. 与参考照片并排时，奶油白羽色、头身关系、站姿、眼睛、喙和腿部方向一致。
3. 动漫感清晰但不拟人；不能再次呈现为小鸡、企鹅、猫头鹰或单纯圆球。
4. 五套羽色、八种姿势、十四个动作、触摸、玩具、PNG 与 GLB 导出继续可用。
5. `npm test`、`npm run build`、桌面端和 390×844 手机端视觉检查全部通过后才发布。

## 回退与风险

- 改造保持在独立鸟模块内，并通过 Git 提交形成可回退节点。
- 程序化基础几何难以表现真实羽毛，但本轮验收重点是轮廓、比例和面部识别，不增加高成本写实羽毛系统。
- 若尾羽或翅膀在某些姿势穿模，优先限制参数边界，不改变公共导出接口。
