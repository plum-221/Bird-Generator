# Bird Generator 设计规格

## 目标

基于 `ringhyacinth/Meow-Generator` 非商业二次开发，保留原版圆润、手绘感、三渲二的可爱 3D 风格与主要功能，将小猫系统完整改造为参数化小鸟生成器。默认预设还原用户提供的白色虎皮鹦鹉，同时支持捏出其他体型和羽色的小鸟。

## 授权与发布

- 仅用于个人展示和非商业发布。
- 保留原项目 `PolyForm Noncommercial License`、原作者署名、第三方许可和原仓库链接。
- 发布到 `plum-221` 的 GitHub 仓库，并通过 GitHub Pages 提供在线网站。

## 技术路线

- Fork 原项目，沿用 `Three.js + Cannon-es + Vite`、相机、物理、天气、导出、多语言和响应式布局。
- 不在猫模块上持续堆补丁；新增边界清晰的 `birdBuilder`、`plumage`、`birdMotion`、`birdToys` 模块。
- 猫专属实现迁移完成后移除，公共能力继续复用。

## 角色与参数

- 默认白色虎皮鹦鹉：奶油白羽毛、圆润微胖体型、小黑豆眼、浅黄弯喙、淡灰粉脚爪和呆萌站姿。
- 身体：胖瘦、身高、蓬松度、头身比。
- 头脸与喙：额头、脸颊毛、眼睛、瞳孔、喙长宽弯曲和颜色。
- 羽翼与肢体：翅膀长度和贴合度、尾羽长度和张开度、腿长、脚爪和站姿。
- 羽色：底色、脸色、翅纹、斑点和渐变；提供白色、蓝白、黄绿、纯黄等预设。

## 动作、互动与场景

- 待机与动作：呼吸、眨眼、歪头、抖羽、蓬毛、伸展、啄食、走动、跳跃、扇翅和短距离飞行。
- 互动：摸头、碰喙、托起、站上手指或栖木。
- 玩具：铃铛、秋千、谷穗、小球和镜子，沿用物理抓取与投掷框架。
- 保留原版天气体系，将鱼雨改为谷子雨；动作模式继续支持键盘控制。

## 界面、数据与导出

- 沿用原版布局和操作逻辑，替换为鹦鹉主题图标与文案。
- 相同种子稳定恢复体型、羽色、姿势、场景、收藏编号和稀有度。
- 保留中英日三语、桌面与移动端、PNG 收藏卡、GLB、参数分享和本地存档。
- 纯浏览器运行，不增加账号、后端或分析系统。

## 异常处理与性能

- 参数统一限定安全范围，极端组合不得产生破面、NaN、骨骼翻转或不可恢复状态。
- WebGL、导出或存档失败时给出可理解提示，不丢失当前参数。
- 移动端自动降低羽片层次、阴影与粒子密度，保持交互可用。

## 验收标准

- 默认角色能明显对应参考照片，且整体观感与原版可爱风格一致。
- 原版主要功能均有鸟类语义对应；参数连续调整稳定，动作衔接自然且无明显穿模。
- 固定种子可复现；PNG、GLB、分享参数和存档可正确导出、导入。
- 自动测试覆盖参数边界、种子复现、动作状态机和导出；桌面与手机浏览器完成实机验收。
