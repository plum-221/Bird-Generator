# 鹦鹉脸部简化设计

## 目标

让默认鹦鹉的脸部更平整、干净，解决腮部鼓起和喙旁小点过多的问题。

## 已确认方案

- 将左右球形腮部替换为贴在脸部表面的淡色平面圆片。
- 平面腮色不使用立体描边，不产生球形凸起感。
- 删除左右共四个喉斑小点。
- 保留黑色鼻孔、眼睛高光和少量额头细纹，维持虎皮鹦鹉辨识度。

## 改动边界

- 只修改 `src/birdBuilder.js` 的脸部细节构建。
- 不改 SDF 身体、翅膀、尾羽、脚、动作、参数、羽色预设或台词。
- 所有羽色预设沿用各自现有腮色，只改变表现方式。

## 验收标准

- 正面和三分之四视角看不到鼓起的球形腮部。
- 喙旁不再出现四个装饰小点。
- 鼻孔、额纹、眼睛与喙保持完整。
- 鸟体结构测试、动作测试和生产构建通过。
