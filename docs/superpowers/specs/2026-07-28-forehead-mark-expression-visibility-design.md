# 表情期间额头羽纹可见性修复设计

## 目标

在保留十种表情现有头部动作幅度的前提下，确保六根额头羽纹在中性、后仰和低头表情中都不会被头部曲面完全遮挡。

## 已确认根因

羽纹节点始终存在且 `visible=true`。惊讶、受惊和得意表情使头部后仰时，羽纹当前的曲面净空不足，几何体落入头部外壳后方；困倦表情向前低头，因此仍可见。

## 方案选择

采用局部几何修复：只增加额头羽纹沿头部曲面法线方向的净空。此次不降低表情的 `headPitch`，也不把羽纹改成始终朝向相机的屏幕贴片，避免削弱动作或产生漂浮感。

## 实现边界

- 修改 `src/birdBuilder.js` 中额头羽纹的表面锚点净空计算。
- 净空继续按头部半径缩放，并保留小头型的既有额外补偿。
- 不改变羽纹数量、位置分布、颜色、长度、表情状态机或眼睛动画。
- 在 `scripts/test_bird_shape.mjs` 增加几何回归断言，覆盖最强后仰表情下羽纹相对头部曲面的外露距离。

## 验收标准

1. 中性、惊讶、受惊、得意和困倦表情中，六根额头羽纹均可见。
2. 默认、小头和大头参数下，羽纹不陷入头壳，也没有明显悬浮。
3. 全量测试和生产构建通过，现有十种表情动作幅度不变。

## 风险控制

抬高过少不能覆盖后仰角度，抬高过多会像贴纸悬空。实施时取能通过极端表情的最小净空，并以正面及侧前视图复核自然度。
