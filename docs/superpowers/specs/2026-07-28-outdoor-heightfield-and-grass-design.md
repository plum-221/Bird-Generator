# 户外高度场碰撞与毛细草地修复设计

## 问题

V6 户外地面虽然通过 `outdoorTerrainHeight()` 约束角色高度，但渲染几何仍是只有中心与外圈顶点的 `CircleGeometry`，不构成可查询的密集地形碰撞结构，也无法准确表现内部起伏。草地使用三角锥实例，近看呈现孤立尖刺。

## 方案选择

采用移动端友好的统一高度场，而不引入 Cannon 三角网格刚体。模型层生成规则网格高度场，渲染层直接以同一高度场创建三角面，角色落地也通过该高度场双线性采样。地面对象明确标记为 `heightfield` 碰撞体并提供查询接口。

草地移除全部 `ConeGeometry` 草实例，改用由多片分段弯曲双面带状几何组成的草簇。每个草簇包含不同朝向、宽度、高度和弯曲量的草叶，再以 `InstancedMesh` 分布数百簇，总量达到数千片细草叶，同时维持少量 draw call。

## 结构

- `outdoorWalkModel.js`：生成、采样高度场；角色步进允许注入碰撞地面采样器。
- `outdoorScene.js`：从高度场建立渲染网格和碰撞对象；暴露 `getGroundHeight()`；建立弯曲草簇实例。
- `main.js`：角色物理使用户外世界提供的地面采样器。
- `index.html` / `main.js`：移除聊天按钮和多段对话框；靠近 NPC 时将单句气泡投影到该鸟头顶，定时或离开后收起。
- `test_outdoor_walk.mjs`：覆盖高度场内部三角网格、插值采样、跳跃落地及旧尖锥移除。

## 验收标准

- 户外仅有一套地面和一套草地，不与室内旧地面叠加。
- 地面具有内部细分三角网格及 `heightfield` 碰撞标记。
- 玩家行走、跳跃和落地使用与画面一致的高度场。
- 户外场景不再创建草地 `ConeGeometry`；近景可见连续细长草叶簇。
- NPC 不再进入对话流程，不显示聊天键；只自动显示一条头顶短气泡。
- 桌面与 390×844 手机端画面、移动、跳跃和性能正常。
