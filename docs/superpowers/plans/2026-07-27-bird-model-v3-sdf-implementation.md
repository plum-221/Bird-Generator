# 鹦鹉模型 V3 SDF 实施计划

## 成功标准

- 连续头颈身体使用 `meshFromSDF()` 生成。
- 翅膀、尾羽和脚的根节点满足 V3 解剖位置断言。
- 气泡字典不再包含猫咪身份、吃鱼或猫科行为。
- 七组以上自动测试、生产构建、桌面和手机截图均通过。

## 步骤

1. 测试先行
   - 扩展鸟体结构测试，检查 `modelVersion=sdf-v3`、SDF 网格模式及肩背/臀中线/腹底挂点。
   - 新增台词测试，扫描中英日字典中的猫科禁词。
   - 验证：旧 V2 模型和旧台词按预期失败。

2. 构建 SDF 主体
   - 用椭球 SDF 和 smooth-min 融合头、颈、胸腹、背部与肩部。
   - 使用 draft/full 两档 Surface Nets 网格精度，保留透明命中网格与构建耗时。
   - 验证：结构测试和构建通过。

3. 重建解剖挂点
   - 翅根固定到肩背；折翼沿体侧向尾部收束。
   - 尾根固定到臀部中线；锥形羽片向后下方叠放。
   - 双腿从腹底连接，双脚前二后二并贴地。
   - 验证：挂点元数据、部件名称及视觉截图通过。

4. 校准动作
   - 将头部微动限制在面部/头部控制节点；翼和尾只围绕各自根节点旋转。
   - 校准 14 个动作，避免从胸前展翅或尾根漂移。
   - 验证：动作测试通过。

5. 重写三语台词
   - 将主角色从 `cat` 改为 `bird`，重写鸟、玩具鱼、小鸭和天气语句。
   - 保留控制器接口，但所有角色选择和气泡诊断使用 `bird`。
   - 验证：禁词扫描和气泡回归测试通过。

6. 浏览器与发布
   - 桌面、390×844 手机端检查部件位置、地面接触与气泡内容。
   - 运行完整测试、生产构建和差异检查。
   - 更新记录、项目总览，提交推送并验证 GitHub Pages。

## 改动边界

- 主要修改：`src/birdBuilder.js`、`src/speechBubbles.js`。
- 配套修改：`src/birdMotionRig.js`、鸟体与台词测试、项目记录。
- 不改：场景、相机、玩具物理、天气渲染、分享卡、品牌图与部署架构。
