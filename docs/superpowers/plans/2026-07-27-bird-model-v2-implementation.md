# 鹦鹉模型 V2 实施计划

## 目标

在不改动公共场景和交互架构的前提下，重建默认鹦鹉可见几何，使其具有直立梨形体态、贴身翅膀、长尾、虎皮鹦鹉面部和轻量日系动画质感。

## 实施步骤

1. 扩展鸟模型测试
   - 为默认参数、关键部件名称、尾羽数量、眼睛高光和对趾脚爪增加结构断言。
   - 验证：新断言在旧模型上失败，证明测试覆盖本次差异。

2. 重建 `birdBuilder.js`
   - 使用旋转剖面构造梨形身体，重做头身连接、胸腹、贴身水滴翼和分层长尾。
   - 把面部挂到头部局部坐标，新增上下喙、鼻蜡膜、高光眼、额纹、脸颊羽和喉点。
   - 重做双腿与前二后二脚趾，缩细暖灰描边。
   - 保持 `fur` 命中体和 `userData` 公共契约。
   - 验证：结构测试与生产构建通过。

3. 调整默认参数、羽色与动作
   - 收窄默认圆润度，拉长尾羽，校准奶油白/象牙白/暖阴影色。
   - 将待机改为胸腹起伏、偶发歪头、翼抖和尾羽回弹；校准 14 个动作锚点。
   - 验证：参数边界、动作测试通过。

4. 重新制作品牌图
   - 以真实照片为形态参考生成透明背景日系赛璐璐鹦鹉，替换当前泛用鸟图。
   - 验证：透明边缘、奶油白羽色、黑眼、钩喙、长尾与模型方向一致。

5. 浏览器视觉验收
   - 桌面端与 390×844 手机端截图，与参考照片并排检查轮廓和面部。
   - 验证：不再像圆球小鸡，默认姿态可辨认是虎皮鹦鹉。

6. 回归与发布
   - 运行 `npm test`、`npm run build`、`git diff --check`。
   - 更新项目记录和总览，提交并推送，等待 GitHub Pages 成功后验证 HTTP 200 与线上截图。

## 变更边界

- 主要修改：`src/birdBuilder.js`。
- 必要配套：`src/birdParams.js`、`src/birdPresets.js`、`src/birdMotionRig.js`、鸟模型测试、品牌图。
- 不改：天气、玩具、分享卡、三语 UI、场景相机和部署架构。
