# Bird Generator

English · [中文](README.md) · [日本語](README.ja.md)

A playful procedural 3D bird creator built with Three.js. Its default character is a round cream-white budgerigar based on the user's real pet; body proportions, wings, tail, eyes, plumage, poses, toys, weather, and motion can all be customized.

▶ [Try it online](https://plum-221.github.io/Bird-Generator/)

## Features

- Five deterministic plumage presets and editable colors
- Eight static poses and fourteen procedural bird actions
- Toon shading, hand-drawn outlines, physics toys, weather, and seed rain
- PNG keepsake cards, GLB export, local parameter handoff, and deterministic seeds
- Chinese, English, and Japanese UI; desktop and mobile layouts

## Run locally

```bash
npm install
npm run dev
```

Run `npm test` and `npm run build` before publishing.
