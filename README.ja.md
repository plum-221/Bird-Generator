# Bird Generator

[English](README.en.md) · [中文](README.md) · 日本語

Three.js で作られた、遊び心のあるプロシージャル 3D 小鳥ジェネレーターです。デフォルトはユーザーの実在するペットをモデルにした、丸くてクリーム白のセキセイインコです。体型、翼、尾羽、目、羽色、ポーズ、玩具、天気、モーションを調整できます。

▶ [オンラインで試す](https://plum-221.github.io/Bird-Generator/)

## 主な機能

- 再現可能な 5 種類の羽色プリセットとカスタムカラー
- 8 種類の静止ポーズと 14 種類のプログラム式モーション
- トゥーン表現、手描き風アウトライン、物理玩具、天気、シードの雨
- PNG 記念カード、GLB 出力、パラメータ受け渡し、固定シード
- 中国語・英語・日本語 UI、デスクトップ・モバイル対応

## ローカル実行

```bash
npm install
npm run dev
```

公開前に `npm test` と `npm run build` を実行してください。
